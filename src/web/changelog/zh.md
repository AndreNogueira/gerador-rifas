# 更新日志（中文摘要）

`../CHANGELOG.md` 的翻译摘要：版本、分节和条目相同，但更简短。完整内容为葡萄牙语。

## 3.95.0 — 2026-11-27

### 修复
- **页面加载后首页标题**：原来只显示「Gerador de Rifas」，而不是服务器已经发给不执行 JavaScript 的访客的完整标题；现在 React 会恢复正确的标题。
- **页头的视觉跳动**：计算名称旁边能放下什么，曾经会让页头短暂地变成两行，把页面其余部分往下推；找到了真正原因（不是广告）并修复了。

### 改进
- **首页挂载后不再丢失说明和指南**：「使用方法」、教程、视频、「关于」和「如何操作」指南现在也出现在页面正文里，不只在「帮助」菜单中。
- **各语言并行加载**：请求界面文字时不再只为了决定页面语言而等待语言列表，这在手机和慢速网络上加快了首次有内容的渲染。
- **「如何为教会举办抽奖」指南更有自己的声音**：与教会议会一起决定，可核实的开奖作为对买家信任的回应，不再指明某个具体的地方机构（因地区而异）。

## 3.94.0 — 2026-11-26

### 修复
- **图库面板在手机上的字体过小**：在「没有模板？从图库中选一个」面板中，「奖品数量」列表、日期格式和「日期前的文字」字段的文字只有 14 px，和上个版本已修复的三个字段一样。现在至少为 16 px。
- **只有真正缺少时，第 2 步才显示「（必填）」**：选择图库模板后（已自动带来数字），只要该字段已填好，第 2 步的标题就不再显示「（必填）」。

### 改进
- **首页描述不再要求使用 Canva**：搜索引擎中显示的描述此前只提到 Canva 模板；现在也说明可以改为从图库中选择现成的模板。

## 3.93.0 — 2026-11-26

### 修复
- **手机上三个输入框的字太小**：每个文件的最大数量、数字颜色和文件名这三个输入框的文字小于16px，导致iOS Safari在聚焦时自动放大。现在它们和旁边的输入框一样大了。

### 改进
- **"关于"现在会说明是谁制作了抽奖券生成器**：当服务负责人已设置（与条款和隐私页面相同的设置）时，"关于"页面现在会说明是谁创建并维护它，以及Windows应用先于网页版出现。

## 3.92.0 — 2026-11-26

### 修复
- **网站上「第 4 步·存放位置」的文字**：教程和首页原本写着「选择保存 PDF 的文件夹」，这只在 Windows 应用中成立——在网站上，文件会由浏览器自动下载。网站文字已不再提及任何文件夹。

## 3.91.0 — 2026-11-26

### 改进
- **模板图库现在和上传模板具有同样的视觉权重**：在首页，选择一个现成的设计（不需要 Canva）不再是隐藏在 PDF 上传下方的次要链接——现在它有一个同样醒目的框。
- **页面之间的更多链接**：抽奖和价目表指南现在链接到各自的工具（`/sorteio`、`/precario`），而不是链接到抽奖券生成器，首页现在也链接到「怎么做」指南索引（`/como-fazer`）。

## 3.90.0 — 2026-11-26

### 修复
- **葡萄牙语页面不再自己切换语言**: 访问不带语言前缀的地址（如 `/`、`/tutorial` 等）时，如果浏览器没有声明语言是葡萄牙语——这是许多搜索引擎爬虫和部分浏览器的情况——网站会自动把网址和全部内容改写成英文。现在不带前缀始终表示葡萄牙语，这正是原本的设计；带前缀的21种语言照常工作。`robots.txt` 也不再完全屏蔽 `/api/linguas`、`/api/textos`、`/api/guia(s)` 以及公开 API 的文档（`/api/v1/docs`），让搜索引擎能够正确渲染和收录网站。

### 改进
- **语言选择器更快**: 选择器中各语言的本地名称（如「Tiếng Việt」或「Čeština」）现在使用系统字体而不是品牌字体，页面不再需要额外下载字形来显示它们——这以前会拖慢正文的显示，有时还会让它跳动一下。

## 3.89.0 — 2026-11-26

### 改进
- **价目表再添三个轮廓图标库：Tabler Icons、Lucide 和 Material Symbols**（均不要求署名）：100 多个项目获得了来自这些库的备选图标，都是逐一挑选、确保真正代表该项目（与之前的图标库不同，这些无法自动匹配）。与彩色图标不同，这些图标会按当前文字的颜色上色——网站、Windows 应用或 PDF 中选择的纸张颜色——因此在深色主题或深色纸张上永远不会变得看不见。
