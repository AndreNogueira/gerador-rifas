# 변경 내역 (한국어 요약)

`../CHANGELOG.md`의 번역 요약입니다. 버전, 구역, 항목은 같고 더 짧습니다. 전체 내용은 포르투갈어입니다.

## 3.35.0 — 2026-11-13

### 새 기능
- **Windows 앱 2.6:** «Extras» 메뉴에 «요청 저장…»과 «요청 열기…»가 생겼습니다(번호, 이름, 시리즈, 색상, 재단선을 담은 .rifas 파일이며 템플릿과 경로는 없습니다). 템플릿 편집기에서 이미지(PNG 또는 JPG)를 추가할 수 있고, «보기 → 비주얼»이 2개에서 사이트의 14개 테마로 늘었습니다(색상만). 2.4 이후의 변경도 포함됩니다: 편집기, 갤러리 24개 디자인, 22개 언어.

## 3.34.0 — 2026-11-13

### 새 기능
- **새 «방법» 안내 3편:** «클럽용», «소방대용», «동네 축제용»(하단 링크). 각각의 경우에 추첨 행사를 단계별로 안내합니다. 22개 언어로 제공되며 허가가 필요한지 지자체에 확인하도록 알려 줍니다.

## 3.33.0 — 2026-11-13

### 새 기능
- **일괄 처리용 공개 API**(`/api/v1`, Swagger는 `/api/v1/docs`): 다른 프로그램이 하나의 템플릿으로 여러 추첨권 작업을 만들 수 있습니다. 키, 일일 할당량, 제한이 있으며 사이트 이용자가 항상 먼저입니다.

- **검색 엔진용 텍스트를 언어별로 편집:** 운영자가 관리 패널에서 각 언어의 제목, 설명, 가이드를 편집하며, 데이터베이스에 저장되어 새로 배포할 필요가 없습니다.

## 3.9.0 — 2026-11-08

### 새 기능
- **대형 화면**(4K, 울트라와이드)과 **최신 휴대폰**을 위한 레이아웃: 간결한 머리글과 44px 버튼.
- 브라우저가 페이지 안에서 PDF를 보여 줄 수 없을 때(안드로이드 Chrome) 미리보기는 이미지를 보여 줍니다.
- 관리 패널은 개인 정보를 저장하지 않고 **화면 유형**(분류, 크기, 계열)을 기록합니다.
- 서비스가 잠들지 않도록 10분마다 스스로를 호출합니다.

## 3.8.0 — 2026-11-08

### 새 기능
