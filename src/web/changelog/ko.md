# 변경 내역 (한국어 요약)

`../CHANGELOG.md`의 번역 요약입니다. 버전, 구역, 항목은 같고 더 짧습니다. 전체 내용은 포르투갈어입니다.

## 3.76.0 — 2026-11-20

### 새 기능
- **가격표에 내 사진**: 품목마다 «사진»을 눌러 아이콘 대신 내 이미지(PNG 또는 JPG)를 넣을 수 있습니다(가격표당 최대 20장, 사이트와 Windows 앱). 사진은 내 컴퓨터에서 줄여지며 미리보기와 PDF를 그리는 데만 쓰입니다. 서버, 가격표 파일, 공유 링크에는 저장되지 않습니다.

## 3.75.0 — 2026-11-20

### 새 기능
- **링크로 가격표 공유**(사이트에서, 서비스에 데이터베이스가 있을 때): 가격표 페이지의 «링크로 공유»는 누구나 열어서 가격표(글, 품목, 가격, 디자인)를 보고 이어서 만들 수 있는 링크를 만듭니다. 마지막 접속 후 90일 동안 보관되며 공유한 사람에 대한 정보는 남지 않습니다. 개인정보 처리방침도 업데이트했습니다.

## 3.74.0 — 2026-11-20

### 새 기능
- **가격표의 두 가지 크기**: «두 가지 크기(품목당 가격 2개)»를 켜면(사이트와 Windows 앱) 품목마다 가격을 두 개(예: 작은 것과 큰 것, 단품과 세트) 적을 수 있습니다. 두 열은 나란히 정렬되어 출력되고, 위에 고른 이름(기본값 «소»와 «대»)이 붙으며, 가격표 파일에 저장됩니다.

## 3.73.0 — 2026-11-20

- 두 페이지와 '댓글', '문제 신고' 버튼은 머리글, 메뉴, 바닥글에 눈에 띄게 있으며, 개인정보 처리방침(22개 언어)이 저장 내용을 설명합니다.

## 3.47.0 — 2026-11-15

### 개선
- **템플릿 갤러리:** 일부 테마에서 디자인 목록이 잘리거나 엉뚱한 곳에 뜨던 문제를 고쳤습니다. 각 상품에 번호가 붙고, 모든 입력란에 글자 수 한도(예: 12/50)가 표시되며, '이 템플릿 사용' 버튼이 마지막 입력란에 붙어 있지 않습니다.
- **추첨 날짜 전용 달력:** 브라우저의 입력란('yyyy. mm. dd.' 표시와 사이트와 다른 언어의 선택기) 대신 22개 언어를 지원하는 달력이 생겼습니다. 월과 요일은 선택한 언어로 표시되고, 날짜는 그 언어의 표기법대로 쓰이며, 한 주의 시작 요일도 맞고, '오늘'과 '지우기' 버튼도 있습니다. 키보드(화살표, Page Up/Down, Home/End, Enter, Esc)로 사용할 수 있습니다.
- **더 자세해진 '정보':** 글을 22개 언어로 새로 써서 생성기가 누구를 위한 것인지, 무엇을 하는지, 인쇄 후 무엇을 하면 되는지, 개인정보를 어떻게 보호하는지, 어디서 쓸 수 있는지 설명합니다.
